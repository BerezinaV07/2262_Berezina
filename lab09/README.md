```

```

    if not i:
        return []
    res=[num[x] for x in i]
    return res
lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
print ('Test 1', sublist(lst, 0, 2, 5))
print ('Test 2', sublist(lst))

### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

```
def gen(x):
    yield x
    while x!=1:
        if x%2==0:
            x//=2
        else:
            x=3*x+1
        yield(x)
```

**seq** *будет задавать последовательность из каждого второго элемента* **seq**.

```

    ...
```
*Ниже приведены примеры использования генератра.*
```
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8
>>> print(sum(every_other(map(int, input().split()))))
2 5 11 3 8
21
```

```
def every_other(seq):
    it=iter(seq)
    x=next(it, None)
    while x!=None:
        yield x
        x=next(it, None)
        x=next(it, None)
```

###  Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция?*
*Что делает функция* **wrapper**?
*Придумайте несколько примеров использования* **toint**.

В toint передается функция fun, которую мы оборачиваем. Эта функция принимает числовые аргументы

toint возвращает вложенную функцию wrapper. Получается wrapper можно вызвать как обычную функцию

wrapper сначала собирает все позиционные аргументы в кортеж, потом преобразует их в int, 
после этого распаковывает полученные целые числа обрато в позиционные аргументы. Псоле этого вызывает исходную функцию fun уже с целочисленными аргументами.
И в конце возвращает результат. 

Примеры использования:

```
mx=toint(max)
print(mx("3", "10", "7"))
```
Выведет 10
```
pw=toint(pow)
print(pw("2", "10"))
```
Выведет 1024
```
def mul(a, b):
    return a * b
ml=toint(mul)
print(ml("4", "5"))
print(ml(2.7, 3)) 
```
Выведет 20 и 6
